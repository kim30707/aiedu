태블릿에서 직접 찾고,
설정으로 고치는 소리 탐정

목표는 ‘정답 버튼 누르기’가 아닙니다. 같은 패드의 정상·현재 소리를 비교하고, 증거와 추측을 나눈 뒤, 소리 연결·높이·음량을 직접 바꾸고 검증합니다.

대상: 초5~6 기준　|　2인 1기기　|　15~20분 모듈　|　권장 진행: 18분
국악강사: 듣기·용어·소리 비교 / AI 담당: 태블릿·설정·검증 지원

수업 전 3분 점검

  • 기기 전체 음량을 낮추고 웹악기의 소리를 켭니다. 실제 학교 태블릿·브라우저·스피커에서 정상 음원 재생을 확인합니다.
  • 오류찾기 탭의 ‘새 문제 시작’을 사용합니다. 문제 번호가 같으면 같은 패드에 같은 오류가 생깁니다. v0.6 수업 기본은 ‘높이 탐정 · 가야금’ 1종입니다. 12개 줄 가운데 한 줄이 한 옥타브 높습니다. 연결·무음 문제는 소리 설정 → 수업 설정의 ‘오류 찾기에서 다른 문제도 보기’를 켰을 때만 나오며, 무음 문제는 목록 처음 8개 안에서 찾습니다.
  • 학년은 소리 설정 → 수업 설정에서 고릅니다. 저학년(초1~3)은 모든 악기 쉬운 연주, 고학년(초4~6)은 가야금·장구 실물 주법과 해금·아쟁 쉬운 연주, 중학생은 모두 실물 주법입니다. 여러 태블릿을 같은 설정으로 열려면 화면에 나온 주소를 씁니다.
  • 국립국악원 공식 녹음과 학습용 변형음을 구분합니다. 앱 설정이 맞아졌다는 판정은 실제 악기 조율·국악 청음 검수 완료를 뜻하지 않습니다.
  • 기기 저장 제한 안내가 뜨면 기록 파일 내려받기를 사용합니다. 학생 실명·학교·연락처·음성녹음은 입력하지 않습니다.

18분 진행표

시간단계교사 발화·학생 행동
0~3분① 정상 듣기“지금 소리의 이름과 특징을 기억해요.” 정상 원음을 먼저 듣습니다. 이 버튼은 학습 오류를 우회합니다.
3~7분② 문제 탐색“같은 패드를 정상·현재로 번갈아 들어요.” 악기와 패드를 골라 비교합니다. 장구는 덕·쿵 두 패드를 확인합니다.
7~10분③ 증거·추측“들은 사실과 원인 생각을 따로 적어요.” 두 칸에 짧은 문장을 적은 뒤 다음 단계로 이동합니다.
10~15분④ 직접 수정“한 설정씩 바꾸고 다시 들어요.” 연결할 소리·높이·음량을 학생이 직접 바꿉니다. 수정 전후 JSON을 읽습니다.
15~18분⑤ 다시 검증마지막 수정 뒤 문제였던 모든 패드를 연구실의 정상·현재 버튼으로 재청취합니다. 전체 설정 검증 후 근거를 설명합니다.

15분형: 탐색·수정에서 각 1분, 정리에서 1분 단축. 20분형: 마지막 2분을 역할 교대·기록 내보내기에 사용합니다. 기존 80분 교안 전체를 이 18분으로 대체한 것은 아닙니다.

태블릿에서 찾는 방법

악기 목록 → 찾아볼 패드 목록 → 정상 원음 듣기 / 현재 문제음 듣기를 번갈아 터치합니다. 실물 주법 화면은 해당 조율·주법의 음을 사용하므로 모든 녹음 패드를 직접 노출하지 않습니다. 오류 찾기 목록에서 문제 패드를 탐색하며, 최종 청취 확인은 연구실의 두 듣기 버튼을 사용합니다. 두 학생은 탐색자·기록자 역할을 한 문제 뒤 바꿉니다.

실패한 재생은 ‘들음’으로 기록되지 않습니다. 음원·소리 준비가 안 되면 먼저 해결하세요. 90초 안에 복구하지 못하면 다른 모둠 화면의 비교를 함께 듣고 종이 활동지에 관찰을 남깁니다. 실제 기기 검증 성공으로 기록하지 않습니다.

세 가지 문제와 복구 원리

문제심은 설정학생이 확인할 복구
연결 탐정장구 덕·쿵 두 패드의 sourceGroup을 서로 교환.각 패드의 sourceGroup을 자기 groupIndex로 되돌립니다. 두 패드 모두 재청취.
높이 탐정가야금 12개 줄 가운데 한 줄에 cents=1200. (v0.6 수업 기본)같은 원음보다 한 옥타브 높은 변형을 비교하고 cents=0으로 수정.
사라진 소리해금(없으면 가능한 현악) 처음 8개 안 한 패드에 gain=0.전체 기기 음량이 아닌 해당 패드 gain=1로 수정.

높이 대상은 문제 번호를 12로 나눈 나머지에 1을 더한 줄입니다(예: 5번 → 6현, 12번 → 1현). 무음 대상은 문제 번호 % min(패드 수, 8) 번째입니다. ‘번호로 섞기’는 번호를 3으로 나눈 나머지로 문제 종류를 고릅니다. 번호와 종류를 기록하면 재현됩니다.

설정 코드는 무엇을 바꾸나요?

{
  "instrument": "gayageum",
  "groupIndex": 3,
  "sourceGroup": 3,
  "cents": 0,
  "gain": 1
}

예시 번호 3은 화면의 #3입니다. groupIndex=바꿀 패드, sourceGroup=재생할 소리, cents=높이 변화, gain=음량 배율. 같은 악기의 유효한 패드만 연결하고 높이 -1200~1200 정수·음량 0~1.5만 허용합니다. 임의 JavaScript를 실행하지 않습니다.

성공 판정과 되돌리기

  • 관찰·추측을 적고 학생 설정 변경이 있어야 합니다. 마지막 수정 뒤 원래 문제 패드 모두의 정상·현재 소리를 재청취해야 합니다.
  • 처음 문제뿐 아니라 전체 목록의 변경 설정이 모두 기준이어야 통과합니다. 다른 정상 패드를 망가뜨렸다면 통과하지 않습니다.
  • ‘직전 수정 되돌리기’는 학생의 마지막 변경을 취소합니다. 다시 들은 뒤 판단합니다.
  • ‘정상 복원 · 연습 종료’는 학습 오류를 해제하며 성공 처리하지 않습니다. 연주 탭에서도 학습 오류 배지가 켜져 있으면 먼저 상태를 확인합니다.
  • 이어 하기에는 최신 악기 목록과 같은 기록만 사용합니다. 불러온 기록은 재청취·재검증해야 하며 저장 실패는 파일 내보내기로 대응합니다.

AI·평가·기록 경계

앱은 외부 AI API에 연결되어 있지 않습니다. ‘요청문 만들기’는 관찰 문장을 정리할 뿐 자동 전송하지 않으며 API 키도 받지 않습니다. 실제 AI 비교가 필요하면 학교가 허용한 서비스에서 강사가 직접 중계하고, 실제 사용 여부를 기록합니다.

관찰: 같은 조건으로 비교했는가? 추론: 사실과 추측을 나눴는가? 수정: 한 설정의 이유를 설명하는가? 검증: 재청취하고 다른 패드도 보존했는가? 속도나 완벽한 연주를 기준으로 등급화하지 않습니다.
