내부 준비본 · 제출·게시 전 · 맥 모의 검사만(실제 태블릿 0회)
정규 수업은 ‘기록 없는 판’이 기본입니다. 교실 서버판은 방과후·특강·시연과, 학교가 심의·개인정보 절차를 마친 경우에만 씁니다.

1. 이 앱이 다루는 것

이름·학교·반·연락처는 받지 않습니다. 다만 선생님이 누가 어느 자리에 앉았는지 아는 교실에서는, 자리 번호에 묶인 점수·자리 현황·조율·대결 기록도 학생 개인정보로 볼 수 있습니다. 그래서 판을 둘로 나눴습니다.

기록 없는 판(정규 수업 기본)교실 서버판
태블릿이 교탁으로 보내는 것학생 값은 보내지 않습니다. 태블릿이 기기에서부터 막고(보내기 기능이 꺼짐 · 판을 서버에 묻는 동안에도 막음 · 교실 서버가 아닌 주소면 기록 없는 판으로 엶), 서버도 받는 길을 닫아 둡니다. 판·시계·‘같이 시작’·대결 문제를 묻는 요청만 오갑니다.자리·모둠 번호와 지금 화면·악기·소리 준비(2초마다), 점수(누를 때), 모둠 조율 제출(모둠 번호만 남김), 대결 되돌림(모둠 번호만 남김), 기기 표(뜻 없는 8글자, 같은 자리 사칭을 막는 데만 씀)·수업 열쇠
자리 번호고르지 않음고름(처음 쓴 기기에 묶임)
점수·결과그 화면에만 보임 · 결과 코드 없음 · 우수팀은 선생님이 듣고 고름교탁 점수판(최소 제출 3명 기본 · 모둠 평균은 서버가 셈). 결과 코드는 서버 없이 파일로 열 때만 나옴(자리 번호가 들어 있음)

2. 어디에 얼마나 남나

곳기록 없는 판교실 서버판
태블릿캐릭터 꾸미기·설정(소리 크기·효과음·가볍게 보기·손 방향·반주 켬·박마다 강조)·수업 번호(뜻 없는 수)만. 자리·모둠·점수·대결 기록·정간보·행진 작품·G6 응답·박자 보정은 화면 메모리에만(창을 닫으면 사라짐). 조율은 그 탭에만, 수업 번호를 붙여 둠(탭을 닫거나 새 수업이면 지움). 서버가 판을 알려 주면 지난 값을 지움위 값 + 자리·모둠·최고 점수·대결 연습 기록·정간보·행진 작품·G6 응답·기기 표(서버가 판을 알려 준 뒤에만 기기에 씀 · 그 전에는 화면을 가림). 화면마다 3초쯤마다 수업 번호를 봐서 새 수업이면 캐릭터·설정을 뺀 놀이터 값을 지우고 다시 엶
교실 서버(교탁 컴퓨터 메모리)같이 시작·대결 문제(학생 정보 아님). 끄면 사라짐점수(최대 2000건)·자리 현황·조율 제출·대결 기록. 끄거나 ‘수업 끝’을 누를 때까지
교탁 브라우저대결 ‘손 든 순서’(모둠 번호만, 새 문제를 내면 지워짐)남기는 것 없음(점수판은 서버 점수만 봄 · 결과 코드 넣기는 서버 없이 파일로 열 때만, 그 화면 메모리에만). 평균은 선생님이 ‘평균 보이기’를 누를 때 교실 서버가 직접 세어 3명 이상 낸 모둠만 곡·모둠마다 값 하나로 보이고(반주 켬·끔을 나눠 보이지 않음), 한 번 보인 값은 3명 이상 더 내야 바뀜. 보인 값(모둠 인원·평균·정확도·반주 섞임)은 서버가 들고 있어 어느 점수판에서도 같고, 판 확인 전·서버 답을 못 받으면 보이지 않음 · ‘수업 끝’·점수 지우기에 지움. 평균·알림에 자리 번호·개인 점수는 나오지 않음. 3명 이상 늘 때 두 평균의 차이로 ‘새로 낸 사람들의 평균’은 셀 수 있음
파일·외부앱은 파일로 저장하지 않고, 인터넷 밖으로 보내지 않습니다. 화면 접속 주소도 서버 기록에 남기지 않습니다.

3. 지우는 법

누르는 것지워지는 것남는 것
태블릿 ‘이 기기 기록 지우기’그 태블릿의 놀이터 기록(캐릭터 포함). 교실 서버판이면 서버의 그 기기 자리 묶음도 풀고 결과를 알림서버의 점수·조율·대결 기록. 자리 묶음을 못 풀었다고 나오면 교탁 ‘자리 연결 풀기’
교탁 ‘수업 끝 · 교탁·서버 기록 모두 지우기’(서버판)서버의 점수·자리 현황·자리 연결·조율 제출·적용한 조율·대결 기록·같이 시작, 보인 평균. 수업 열쇠·수업 번호를 새로 만듦 → 열린 다른 창(점수판 등)과 태블릿 화면은 다음에 서버에 물을 때(3초쯤) 창마다 지움꺼져 있었거나 와이파이가 끊긴 태블릿(다음에 교실 서버에 닿을 때 지움), 캐릭터·설정
서버 창 닫기(Ctrl+C)서버 메모리 전부. 서버판에서 열려 있던 화면은 2분 넘게 서버가 안 닿으면 그 기기 값을 지우고 그 화면을 가린 채 놀이·소리·타이머를 멈춤(저절로 다시 열거나 되살리지 않음 · 선생님이 서버를 다시 켠 뒤 ‘새로 고침’, 자리 번호는 다시 고름)꺼져 있던 태블릿·닫힌 브라우저에 남은 값(다음에 서버에 닿을 때 지움)

서버판 수업 순서: 수업 끝 → 남길 것은 모둠 단위로 칠판·종이에(자리 번호는 옮기지 않음) → ‘수업 끝 · 모두 지우기’ → 태블릿에 ‘새 수업’이 뜬 것(몇 초)을 본 뒤 서버 창 닫기.

4. AI를 쓸 때

  • 앱은 AI에 연결하지 않습니다. 선생님이나 학생이 카드 글을 학교 계정 AI에 붙여 넣는 순간은 외부 전송입니다.
  • 두 방식 모두 열어 둡니다. ① 교탁에서 강사가 한 번에: 실제 자리·결과 대신 가상 예시를 씁니다(‘7번 왼손’처럼 실제 자리를 넣으면 전송이 됩니다). 종이·코드로 받을 때는 학생마다 다른 코드가 아닌 모두 같은 공통 코드만 씁니다. ② 학교 계정으로 모둠이 직접: 학교가 정한 감독 선생님 아래에서, 이름·학교·반을 넣지 않습니다.
  • 강사 계정을 쓸지는 학교 지침(부산 안내서의 ‘교육용 관리 계정’ 원칙 등)과 맞는지 학교와 확인합니다(확인 필요).

5. 학교와 정할 것(확인 필요)

  • 정규 수업에서 쓸 판(기본: 기록 없는 판), 교실 서버판을 쓸 때 학교 절차
  • 문의 창구·개인정보 보호책임자, 학교와 외부 강사(셈제작소)의 역할(위탁 여부 등)
  • 만 14세 미만 학생: 법정대리인 동의가 필요한지(학교의 처리 근거에 따라 다름)
